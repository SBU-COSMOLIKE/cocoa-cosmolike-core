# 9. What to take from fastnc main, and what must remain from TATT

> **Archive status.** This source study records design proposals and validation requirements, not completed features. Read the [maintained implementation status](../threepcf.md) first. Both the mean and its covariance belong in `cosmolike/3pcf/`; earlier destination proposals using `fastnc/` or `covariances/` are superseded.

**Recommendation.** A CosmoLike implementation should draw its TATT and velocity-shear physics from the pinned TATT source, while assessing the numerical corrections and alternative algorithms in pinned main. Translating the older branch alone would overlook a confirmed FFTLog defect and several useful independent checks. Replacing TATT with main would remove the explicit TATT bispectra needed for the second reproduction target. Neither branch is an unquestioned numerical reference: their conventions must be compared before their predictions can be compared.

This chapter inspects source and commit patches; it reports no executed scientific tests or measured timings. A proposed test below is an acceptance requirement for a later implementation, not evidence that the implementation passes it. The pinned comparison is:

| Source | Commit | Role in this study |
|---|---|---|
| TATT | `7b2336ce37a909bed51f07f32a2a4f096e71b6ce` | Explicit intrinsic-alignment bispectra and historical reproduction reference |
| Main | `e59eab5a07401d2f484bfe00dd48827f2d2162c7` | Numerical corrections, alternative transformations, and comparison calculations |
| Common ancestor | `b384353c001d479c2e144717225f81ee968d047a` | Identifies where the histories separate |

The comparison reports 138 commits unique to main and 15 unique to TATT. Main is therefore not TATT plus a linear sequence of corrections. It replaces the older top-level modules with separate bispectrum, projection, multipole, coupling, Hankel-transform, and three-point-function packages. The mathematical correction in a commit may be relevant even when the file it changed no longer exists in the same location. Conversely, a correction to a refactoring error may already be satisfied by the original TATT code. ## 9.1 A correction is not automatically a correction to TATT

The table separates shared numerical defects from changes that depend on a particular representation. “Import” means preserve the mathematical behavior and its acceptance test in a future C implementation. It does not mean apply the Python commit unchanged.

| Change inspected | What the source actually changes | Applicability and recommended action | Proposed acceptance check |
|---|---|---|---|
| FFTLog filter, `7940b178` | Returns the filtered Fourier coefficients instead of the unfiltered array | **Shared defect:** TATT also calculates the filter and discards its result. Adopt the intended filter behavior, with the historical result separately recorded. | Vary window width, padding, grid length, and integration range; compare interior real-space predictions with independent integration. |
| Legendre normalization, `71687f6f` | Replaces weights proportional to `(2L+1)/2` with weights proportional to `1/2` | **Refactoring correction already satisfied by TATT:** the stored antiderivatives include the factor `2L+1`. Do not divide the TATT answer again. | Recover known Legendre coefficients for a constant and for individual polynomials, including nonzero modes. |
| Centroid phase, `18595bfc` | Changes `exp(+i phase)` to `exp(-i phase)` | **Unresolved convention difference:** current main and TATT give conjugate conversion factors for the same supplied geometry; main's legacy-equivalence docstring contradicts its expression. Reconcile the full convention before adopting either sign. | Derive rotations directly from three Cartesian shear tensors; check all natural components, reflections, and vertex permutations. |
| Coupling spin, `b4265fba` | Changes the spin in the direct coupling integral from vertex 3 to vertex 1 | **Main X1-convention correction:** appropriate when independent Fourier vectors are legs 2 and 3 and the reference vertex is 1. No literal substitution in the older fixed-shear formula is justified. | Compare direct angular quadrature and coupling reconstruction for unequal effective spins and each conjugated shear component. |
| Equal-side analytic multipoles, `2390f3e` | Avoids evaluating a zero prefactor times an infinite angular intermediate | **New-algorithm boundary case:** the changed analytic classes are not the TATT numerical route and have since been reorganized. | Exact squeezed cyclic sum, `8e69f01d` | Replaces a leading squeezed approximation in intermediate main with extended-precision evaluation of the exact cyclic expression | **Useful numerical mechanism, with different histories:** TATT uses direct cyclic sums; it does not contain that intermediate approximation switch. Consider grouped stable evaluation, without importing the discarded approximation. | Compare against a higher-precision reference across the precision-switch threshold and toward flattened triangles. |
| Explicit projection and physical-state tracking | Separates radial coordinates, weights, and physical predictions from reusable transform resources | **Applicable design and tests:** preserve the distinction in C; copying main's entire object hierarchy is unnecessary. | An updated calculation must match a fresh construction after each cosmology, IA, source-distribution, and numerical-grid change. |
| Slepian, semi-analytic, and low-rank routes | Replaces some multidimensional sampling with separable representations and reusable integrals | **Algorithm opportunity:** assess term by term; approximation errors require a separate budget. | Match projected bispectra, natural components, aperture statistics, and parameter derivatives against a converged numeric route. |

## 9.2 Why the normalization and phase checks need derivations

**An apparent missing factor can already be inside an intermediate quantity.** For a Legendre expansion, the coefficient is

```math
b_L=\frac{2L+1}{2}\int_{-1}^{1}d\mu\,B(\mu)P_L(\mu).
```

Both the TATT implementation and corrected main store an antiderivative proportional to $`P_{L+1}-P_{L-1}`$. Its derivative is $`(2L+1)P_L`$, so multiplication by another $`2L+1`$ would count the normalization twice. The factor $`1/2`$ in their integration weights is consistent with the displayed definition; it is not evidence of an omitted angular normalization. This is why reading only the commit title could lead us to damage a correct TATT calculation. The zero mode alone would not expose that error, because its extra factor would be one. [TATT multipoles](https://github.com/git-sunao/fastnc/blob/7b2336ce37a909bed51f07f32a2a4f096e71b6ce/fastnc/multipole.py), [main multipoles](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/fastnc/multipole/decompose.py).

**The centroid conversion contains an actual source discrepancy.** Let $`\alpha_i`$ be the arguments of the three complex vectors from the triangle's vertices toward its centroid. TATT constructs $`q_i=v_i/v_i^*=e^{2i\alpha_i}`$. For its all-unconjugated natural component, its conversion factor is consequently

```math
Q_{\rm TATT}=\exp\{i[2(\alpha_1+\alpha_2+\alpha_3)+3\phi]\}.
```

Main constructs the same centroid vectors and sets the three X-reference angles to $`(-\phi/2,0,-\phi)`$. Its current return expression gives

```math
Q_{\rm main}=\exp\{-i[2(\alpha_1+\alpha_2+\alpha_3)+3\phi]\}
            =Q_{\rm TATT}^*.
```

This is an algebraic comparison of the expressions, without a numerical run. Main's comments claiming recovery of the legacy factor cannot both describe that return expression and the TATT definition above. It does not yet establish which complete predicted observable is wrong: the upstream X-projected field, orientation of the opening angle, or ordering of vertices may also have changed. The resolution requires one written convention shared by the transform and by `3pcf_integrator`. A round-trip conversion is insufficient, because multiplying by a wrong phase and then its inverse still returns the original number. Use non-isosceles triangles with nonzero imaginary components so that conjugation is visible. [TATT conversion](https://github.com/git-sunao/fastnc/blob/7b2336ce37a909bed51f07f32a2a4f096e71b6ce/fastnc/fastnc.py#L752), [main conversion](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/fastnc/threepcf/conventions/projection.py).

**The reference vertex is part of the mathematics.** Main's coupling uses effective spin $`\sigma_i=\epsilon_i s_i`$, where $`s_i=2`$ for shear and $`\epsilon_i=-1`$ indicates complex conjugation. Its angular label is $`\nu_k=k+(\sigma_3-\sigma_2)/2`$, while its spin-dependent coupling phase uses $`\sigma_1`$. Exchanging the reference vertex requires transforming these labels together with the leg coordinates. A test using only $`(2,2,2)`$ cannot distinguish an erroneous use of $`\sigma_3`$ from $`\sigma_1`$. The components $`(-2,2,2)`$ and $`(2,2,-2)`$ can. Main's coupling module also retains explanatory formulas using `h_3` after defining `h_1`; documentation copied from it needs the same algebraic review as executable expressions. [Main coupling definition](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/fastnc/coupling/compute.py).

## 9.3 The shared FFTLog correction changes finite-grid predictions

FFTLog represents a sampled function as a sum of complex power laws on a logarithmic grid. Finite grids create artificial periodic boundaries; filtering high Fourier modes can suppress oscillations caused by those boundaries. In TATT's two-dimensional transform, the code constructs two window arrays and their product with the Fourier coefficients, but returns the original coefficients. The main correction makes the window parameter affect the calculation as intended. This defect is visible by inspection and is independent of the TATT tensor model.

Activating the filter does not preserve the old finite-grid answer exactly, and a stronger filter is not inherently a more accurate answer. It also removes information from the sampled function. The proposed comparison should preserve the original TATT output as a historical reference, then evaluate corrected outputs at several window widths and grid resolutions against an independently converged transform. It should report error where the final angular cuts actually retain data, including squeezed configurations. A claim of reproducing the historical prediction and a claim of correcting its transform are different deliverables; the study needs records for both.

The squeezed cyclic sum raises a related distinction. Individual perturbation-theory terms may be large and cancel in their sum when one wavenumber is small. Evaluating the exact sum with more arithmetic precision can reduce cancellation error without changing the model. Replacing it with only its leading squeezed limit changes the function at finite side ratio. Current main removes such an approximation switch from an intermediate implementation. For C, assess grouped algebra and actual arithmetic precision on the intended machine; do not assume the name `long double` guarantees a particular improvement. Inputs already rounded to double precision, a zero short side, and triangle-boundary handling require their own tests. These are numerical acceptance questions, not a reason to modify TATT amplitudes to force agreement.

The mechanism applies to a specific part of TATT's BiHalofit expression: its three-halo term contains the cyclic sum $`2\sum_{\rm cyc}F_2 P_{E,i}P_{E,j}`$, plus additional fitted terms proportional to `dn`, followed by a common damping product involving `en`. The precision treatment concerns the $`F_2`$ sum. The fitted additions and damping must remain unchanged; replacing the entire three-halo term with a tree-level expression would change the model. Test the tree contribution and the assembled three-halo contribution separately. [TATT BiHalofit assembly](https://github.com/git-sunao/fastnc/blob/7b2336ce37a909bed51f07f32a2a4f096e71b6ce/fastnc/halofit.py#L530).

## 9.4 Main supplies algorithm choices beyond a language translation

**Separable expressions can eliminate repeated integration.** Suppose a bispectrum term can be written schematically as a sum of products $`f_r(k_2,z)g_r(k_3,z)`$ times a known angular function. Sampling every triangle repeats evaluations of those one-dimensional factors. A separable transform can integrate the factors through reusable radial kernels instead. Main's Slepian route uses such representations to construct real-space angular modes directly; its semi-analytic route constructs angular multipoles from structured expressions and then uses the shared coupling and radial transforms. Its hybrid route assigns each additive physical term to an available calculation method and combines the results before the final angular sum. [Main calculation methods](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/docs/user_guide/threepcf.rst).

This creates a different optimization question from replacing Python loops with C loops. We should identify which TATT kernels admit a short separable representation, which require a convergent expansion, and which should remain numerically sampled. The angular dependence of a tensor IA term and the ordered placement of the intrinsic field must survive that decomposition. A scalar matter-bispectrum representation is not sufficient evidence that all TATT components can use it. Start with an exact tree-level matter term and one explicitly derived IA term; retain the numeric evaluator for every proposed structured representation. Any gain then has a traceable origin: fewer mathematical operations, cheaper operations, or less repeated work.

**The one-halo BiHalofit approximation needs its own scientific test.** Main's BiHalofit model exposes an exact numeric one-halo contribution and a trained low-rank representation, with default rank eight and a stored basis named `broad-debug-v1`. Here “rank” counts retained product functions, so reducing it reduces work but can discard shape dependence. The inspected unit test compares three triangles at $`z=0.4`$ with relative tolerance $`2\times10^{-4}`$; another checks that a projected calculation is finite. Those assertions are useful examples of intended behavior, not a bound over DES-Y6 cosmologies, redshifts, triangle shapes, or derivatives. The source also restricts ranks to a supplied set; increasing rank arbitrarily is not an available convergence control. [Model and rank configuration](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/fastnc/bispectrum/models/bihalofit.py), [inspected tests](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/tests/test_bihalofit_bh1_semi_analytic.py).

Before accepting that representation, compare it with the exact numeric contribution across the prior region and through the final aperture estimator. Check parameter derivatives as well as fiducial values. A small pointwise bispectrum error can produce an appreciable derivative error if its parameter dependence is poorly reproduced, and relative error is ill-defined near a zero crossing. Use absolute errors and the covariance-weighted data-vector error there. Keep results obtained with the exact and approximated models separately identified in any performance comparison.

**Main provides a useful independent transform.** `BruteForceX3PCF` uses a one-dimensional FFTLog over a common Fourier scale followed by angular quadrature, bypassing the angular-multipole, spin-coupling, and double-FFTLog chain. Agreement with it tests more than agreement between two translations of the same algorithm. It still shares physical bispectrum inputs and some transform technology, so analytic examples and direct limited-domain quadrature remain useful additional checks. Its optional reduced angular domain assumes exchange symmetry of legs 2 and 3. Ordered mixed-field TATT bispectra need not have that symmetry: retain the full domain unless the particular component proves otherwise. [Independent solver](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/fastnc/threepcf/bruteforce.py).

## 9.5 Preserve the physics, projection units, and parameter dependence

Main includes NLA radial kernels, but its model directory does not supply the TATT/velocity-shear bispectra in TATT's `ia_bispectra.py`. Its README lists IA and semi-analytic IA among expected features. The relevant missing material is the explicit density-weighted, quadratic tidal, and velocity-shear tensor contributions, not all forms of IA. Retain their coefficient normalization, field ordering, and subtraction of the linear-alignment tree contribution when adding the nonlinear matter-plus-NLA base. Updating the transform cannot resolve the paper/source discrepancies listed in [Chapter 1](01_physics_and_reproduction.md). [Main kernels](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/fastnc/projection/kernels.py), [TATT physics](https://github.com/git-sunao/fastnc/blob/7b2336ce37a909bed51f07f32a2a4f096e71b6ce/fastnc/ia_bispectra.py).

Main's explicit line-of-sight projector is a useful reference for a dimensional check. Its finite-width convention integrates $`d\chi\,\chi^{-4}W_iW_jW_k B_{3D}`$; its `delta_like` constructor instead evaluates at one redshift with no integral and no $`\chi^{-4}`$ factor. Those are different mathematical operations. A point evaluation cannot stand in for a normalized narrow source window without accounting for the window integral and its units. Compare numeric and coefficient-level projection with the same weights and integration measure; if using redshift coordinates, include $`d\chi/dz`$. [Projection conventions](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/docs/user_guide/projection.rst).

Reusable geometric transforms must also be distinguished from cosmology-dependent radial weights. Main's `warm_up` prepares structural resources and discards source-dependent predictions, which is an appropriate timing distinction. Its state tracking is useful but not a proof against all stale results: a callable projection prefactor is identified by its object identity, so changing physical values captured inside the same callable may escape that identity check. A C design should use explicit parameter-version tracking and documented ownership of arrays. For every changed parameter, compare update-in-place with a newly constructed prediction; include distances, growth, IA amplitudes, and source redshift distributions. [Projector state](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/fastnc/projection/projector.py), [warm-up and invalidation](https://github.com/git-sunao/fastnc/blob/e59eab5a07401d2f484bfe00dd48827f2d2162c7/fastnc/threepcf/threepcf.py).

**The resulting Fisher studies should cover both DES Y3 and DES Y6.** Y3 supplies a connection to the first paper's survey setup and an opportunity to check whether local Fisher curvature explains its reported posterior improvement. A Fisher calculation is not an exact reproduction of a marginalized posterior result. Y6 then asks how the additional three-point information changes with its own source distributions, calibration uncertainties, angular cuts, and covariance. Branch reconciliation must be identical in both studies; otherwise a survey comparison would mix a changed experiment with a changed numerical model. For the velocity-shear extension, specify the corresponding two-point response or explicitly label the calculation as a restricted model in which that parameter enters only the three-point prediction. Main's NLA kernels and CosmoLike's existing ordinary TATT tables do not establish that missing response. [Inference target](https://arxiv.org/abs/2503.03964), [TATT and velocity-shear target](https://arxiv.org/abs/2601.09133).

## 9.6 A bounded reconciliation plan

1. **Write the mathematical correspondence first.** Record vertex ordering, opening-angle orientation, field conjugations, angular-basis normalization, radial units, IA coefficients, and aperture-estimator conventions. Resolve the centroid-phase discrepancy before labeling either implementation the reference.
2. **Separate historical reproduction from corrected numerics.** Preserve pinned TATT outputs when computation is authorized. Record each accepted numerical correction and its effect on the final observables. Preserve the physical model while testing those corrections.
3. **Compare three calculation methods on common physics.** Use pinned TATT, pinned main's numeric route, and a selected independent integration. Add structured main routes only for terms they actually represent. A timing table that compares an IA-free main calculation with a TATT calculation would answer the wrong question.
4. **Choose the smallest C design that meets the targets.** Import numerical kernels, explicit dependencies, independent checks, and attribution. Defer generic-spin interfaces beyond the requested observables, graph renderers, Python object machinery, and unrelated tracer models. Preserve the capability to add a separately validated IA representation later.
5. **Measure after numerical acceptance.** Compare cold setup, warm physical updates, memory, and complete data-vector time, including `3pcf_integrator` work. Include current main as a performance reference wherever its scientific scope matches. Report approximation error with every structured approximation's timing.

This plan keeps Sunao Sugiyama's and Rafael Gomes's methods identifiable while allowing CosmoLike to exploit their mathematical structure. The expected benefit remains a hypothesis until matched-model, matched-accuracy comparisons establish it. The source inspection already establishes that main contains changes we should assess, that several apparent fixes must not be applied twice, and that the centroid-phase convention needs an explicit reconciliation before a port can claim agreement.
